My pick

The arrow plus months. Kronos already says "this opens" with an arrow on every week, so one more arrow on the head and one on each month band make a single idea at three levels: all, month and week. It frees the line over the table, it needs no new word and it follows DESIGN.md without a new pattern. If you would rather have something nobody else has, the crown is the fun one, and Kronos has one user who will always know what it does. One limit of these mockups: the real table is made of table rows, which can fade in a wave but cannot slide open like this.
